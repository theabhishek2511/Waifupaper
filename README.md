# waifupaper

live wallpaper android app that fetches anime-style images from [waifu.im](https://waifu.im) and cycles through them at a configurable interval.

## features

- set as your device's live wallpaper via android's wallpaper picker
- fetches a fresh batch of images at midnight based on your configured interval
- configurable settings
  - NSFW filter (off / on / all)
  - image orientation (all / landscape / portrait / square)
  - wallpaper change interval
- double-tap the wallpaper to immediately switch to the next image
- smooth crossfade animation between wallpaper changes
- browse all currently cached wallpapers in a grid view

## installation

i'll probably set up releases one day, but right now you gotta build from source.

1. clone the repo
2. open in android studio
3. build and install on your device
4. settings -> wallpaper -> live wallpapers -> select waifupaper
5. tap the gear icon to configure preferences
